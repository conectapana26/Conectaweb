Guía: Reglas de Seguridad

Si ya activaste la autenticación anónima pero se sigue guardando localmente, es porque debes permitir acceso en tus reglas de Firestore. Copia y pega esto en la pestaña "Reglas" de Firestore en Firebase Console:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
